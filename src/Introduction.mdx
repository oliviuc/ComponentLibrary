# Component Library

Customizable wrappers over shadcn. Open a component in the sidebar to see examples and try the controls.

```tsx
import { Button } from "@/components/ui/Button";

export function Example() {
    return <Button>Save</Button>;
}
```

Theme tokens live in `src/assets/css/colors.css`. Use the toolbar to switch light and dark.
