# Component Library

React components (shadcn wrappers) developed and documented in Storybook.

```bash
npm install
npm run dev
```

Storybook runs at [http://localhost:6006](http://localhost:6006).

## Scripts

| Command           | What it does                           |
| ----------------- | -------------------------------------- |
| `npm run dev`     | Start Storybook                        |
| `npm run build`   | Typecheck and build a static Storybook |
| `npm run preview` | Preview the static build               |
| `npm run test`    | Run story tests                        |
| `npm run lint`    | Lint                                   |
| `npm run format`  | Format with Prettier                   |

Import UI components from `@/components/ui`. Theme tokens live in `src/assets/css/colors.css`.
